## 🚀 Instalación en segundos

1. Abre **CloudStream** y entra a **Configuración → Extensiones → Agregar repositorio** (la ruta puede variar según la versión).
2. En el campo **URL o shortcode**, escribe `rbkcloud`.
3. Confirma y abre **RBK Providers Friendly** para elegir las extensiones que quieras instalar.

> [!TIP]
> ¿Prefieres usar la URL completa? Copia esta dirección:
>
> ```text
> https://raw.githubusercontent.com/RUBIKOF/CS-FRIENDLY-RUBIKOF/main/repo.json
> ```

## 🛠️ Estructura del repositorio

```text
CS-FRIENDLY-RUBIKOF/
├── README.md         # Presentación y guía de instalación
├── .github/          # Actualización automática del catálogo
├── repo.json         # Manifiesto del repositorio
├── plugins.json      # Catálogo y metadatos de extensiones
└── *.cs3             # Archivos de las extensiones
```

Los manifiestos son los puntos de entrada del catálogo:

- [`repo.json`](./repo.json) identifica el repositorio y enlaza su lista de extensiones.
- [`plugins.json`](./plugins.json) enumera las extensiones, versiones, tipos de contenido y archivos publicados.

## ❓ Preguntas frecuentes

<details>
<summary><b>¿El shortcode instala todas las extensiones de golpe?</b></summary>
<br>
No. El código <code>rbkcloud</code> agrega <b>el repositorio completo</b> a CloudStream. Después puedes seleccionar qué extensiones instalar.
</details>

<details>
<summary><b>¿Qué hago si el shortcode no funciona?</b></summary>
<br>
Utiliza directamente la <a href="https://raw.githubusercontent.com/RUBIKOF/CS-FRIENDLY-RUBIKOF/main/repo.json">URL del manifiesto repo.json</a>. Ambas vías apuntan al mismo repositorio.
</details>

<details>
<summary><b>¿El repositorio aloja películas, series o canales?</b></summary>
<br>
No. Este repositorio distribuye archivos de extensiones y sus metadatos; el contenido consultado por cada extensión depende de servicios externos.
</details>

<details>
<summary><b>¿Por qué puede dejar de funcionar una extensión?</b></summary>
<br>
Las fuentes externas pueden cambiar su estructura, dominios, restricciones o disponibilidad. Por ello, la funcionalidad de cada extensión puede variar con el tiempo.
</details>

## ⚖️ Aviso importante

Este proyecto distribuye extensiones de terceros o que interactúan con servicios externos. **No aloja archivos de películas, series ni transmisiones de TV.** Los nombres, marcas y materiales de otros servicios pertenecen a sus respectivos titulares. El uso de cada extensión debe respetar las leyes aplicables y las condiciones de los servicios consultados.

Este es un repositorio comunitario y **no es un repositorio oficial del equipo de CloudStream**.
